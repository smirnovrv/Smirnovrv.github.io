# indikova.ru — лендинг косметолога

Статический сайт в папке репозитория. Открывается локально через `index.html` или на GitHub Pages по адресу  
`https://<username>.github.io/indikova.ru/`

## Что заменить перед публикацией

| Файл / блок | Что указать |
|-------------|-------------|
| `img/hero.jpg` | Фото косметолога (рекомендуется 520×640 px) |
| `img/results/` | Фото «до / после» |
| `index.html` → телефон, Telegram, адрес | Реальные контакты |
| Блок «О специалисте» | Имя, образование, опыт |
| Услуги и цены | Актуальный прайс |
| Отзывы | Реальные отзывы клиентов |

## Структура

- `index.html` — одностраничный лендинг
- `style.css` — стили (палитра в духе premium-лендингов)
- `script.js` — мобильное меню и форма заявки
- `favicon.svg` — иконка вкладки

## Форма заявки

Сейчас форма только показывает сообщение об успехе. Для отправки на почку или в Telegram подключите backend или сервис форм (Formspree, Telegram Bot API и т.п.).
